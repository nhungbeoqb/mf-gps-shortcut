Make.fun bounty entry: the GPS's one-line excuse for sending the driver
down the wrong road, in its own voice.

> In my defence, the lake wasn't on the map, the map was from 2019, and the goat nodded like it knew a shortcut.

`main.py` writes that single line (110 characters) to `/output/entry.txt`.
